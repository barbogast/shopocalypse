# Changelog

When a commit changes something users would notice, add a line to
`CHANGELOG.md` in that same commit. It's shown in the app under "Neuigkeiten",
so write it in German, short and from the user's point of view. Skip
refactors, tests, docs and small tweaks. Add to today's `## YYYY-MM-DD`
heading, creating it at the top if it isn't there yet.
